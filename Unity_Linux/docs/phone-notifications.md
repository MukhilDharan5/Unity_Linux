# Phone notifications and incoming SMS on the laptop

Install companion **0.1.14** over the existing APK and update Linux. On the phone, enable **Features → Notifications → Notification mirroring** and allow Android notification-listener access. Enable **SMS** and grant its existing SMS permissions for incoming-message alerts independent of the messaging app. Keep Unity connected over Bluetooth or Wi-Fi / LAN. Android app exclusions and the corresponding Linux feature switches still apply.

New phone notifications and incoming inbox SMS create native desktop popups with the app/sender and a text preview. They work while the Unity window is closed. **Open in Unity** opens the paired device's Notifications or Messages page through the verified installed launcher. No message is sent and no phone notification action is invoked by opening the alert. Desktop notification settings and Do Not Disturb control popup presentation.

Notification updates replace the existing desktop alert, and phone removal closes it. Startup/list snapshots, ongoing notifications and group summaries update the app without new popups. Identical event replays are ignored. Incoming-SMS monitoring establishes a baseline when it starts, so existing history, offline messages, read changes, outgoing messages and delivery reports do not become new-SMS alerts. A uniquely matched inbox row ID lets an SMS and its messaging-app notification share one desktop alert; unmatched app notifications remain independent. RCS/MMS app notifications can mirror normally, but direct inbox monitoring covers SMS only.

The daemon bounds its queue, retained alert IDs and deduplication memory. It rechecks device connection, session generation and feature permission before publishing, and closes private alerts on disconnect or feature revocation. A missing/restarted desktop notification server does not disconnect the phone. OS notification restrictions and phone background policies still require a physical-device check.

`tests/phone_alerts_integration.py` uses real TLS/D-Bus with a private notification service to check previews, escaping, updates/removals, duplicate handling, exact SMS/app correlation, identical texts with different message IDs, permissions, disconnect, quiet reconnect and server recovery. `tests/call_popup_integration.py` checks actual GTK page opening from alert clicks. Android `PushNotificationsTest` checks the real provider observer/listener paths, baseline suppression, opt-out, ongoing/list silence and unambiguous SMS correlation.

Platform references: [Desktop Notifications Specification](https://specifications.freedesktop.org/notification/latest-single/), [Android SMS provider](https://developer.android.com/reference/android/provider/Telephony.Sms), and [message notification timestamps/text](https://developer.android.com/reference/android/app/Notification.MessagingStyle.Message).
